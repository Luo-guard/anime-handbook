# Security and private data

Never commit local databases, account files, WebDAV application passwords, browser profiles, Syncthing device exports, Android signing keys or private record images. Use separate local/online data directories and HTTPS for online deployment. The repository contains source and synthetic/public demo assets, not private accounts or a production data backup.

Do not include credentials, sessions or personal records when reporting a problem in a public issue. For a sensitive report, contact the repository owner privately through an available channel.
