# 动漫手账 · 存视频 1.2.1

## 更新

已从本项目目录加载扩展：在 edge://extensions 或 chrome://extensions 找到扩展，点击重新加载。
使用压缩包：解压到固定文件夹，在扩展管理页开启开发人员模式，加载已解压的文件夹。更新旧版本时可继续使用原文件夹并重新加载，避免安装两个副本。

本次同时需要更新并重启手账后台，再刷新手账页面。扩展权限没有增加。

## 保存与续看

在 B 站 UP 主 BV 视频页，或官方番剧的 /bangumi/play/ss...、/bangumi/play/ep... 页面点击扩展。手账会复用已打开的标签页弹出确认框；选择番剧并点击保存，不会自动写入。

官方番剧保存时读取 B 站公开选集，缓存“本篇集号 → 官方 ep 地址”。之后按第一集未看的本篇直接打开对应 ep；不把 ep 编号当集数，也不把 p 参数用到官方番剧。日常打开无需再次请求选集。重新保存同一视频可刷新连载新增选集；如果刷新失败，会保留已有缓存。首次保存无法取得选集时会明确提示重试。

BV 合集仍按一集对应一 P 跳转。OP/ED 不计入本篇进度。没有匹配选集时保留原保存地址，不猜测下一集。

此前作为“其他链接”保存的官方页面，需要重新选择“视频”保存一次，才能设为默认视频并自动续看。旧条目不会被擅自批量转换。

选集链接不改变 B 站原有的播放权限、地区或会员要求。APK 本次未改动。
