# 动漫手账 · 存视频（Edge / Chrome，v1.1.1）

## 安装 / 更新

首次：在 `edge://extensions`（Chrome 为 `chrome://extensions`）开启开发人员模式，加载本目录，并固定扩展到工具栏。

已安装：在扩展管理页找到本扩展，点击重新加载。无需重装，也无需重启后台。新版使用标签页地址读取权限查找本机手账；更新时若浏览器提示权限变更，请确认后启用。

## 保存视频

1. 启动本机手账后台。
2. 在 B 站 BV 视频页面点击工具栏的扩展图标。
3. 浏览器会打开本机手账的“保存 B 站视频”确认框。
4. 选择番剧，填写可选的简体 / 繁体备注，点击“保存视频”。保存后进入番剧详情。

取消不会写入任何数据。分 P 会保留，跟踪参数会在保存时去除。以后在番剧详情点击“打开已存视频”即可直达。

从番剧详情点击 B站搜索时仍可携带番剧关联，首次安装后需要刷新手账页面。独立打开视频或新标签页无法关联时，请手动选择对应番剧。保存使用手账当前账号，账号切换后服务端会校验拒绝旧确认请求。

## v1.1.1 的连接方式

扩展仅负责读取用户主动点击的当前视频，并通过地址片段传给本机手账确认页面。不再从扩展请求本机接口，也不依赖手账标签页消息桥；所有读取、确认和写入均在手账同源页面完成。进入确认框不自动保存。

本版不再出现旧的扩展弹窗或“本机后台未连接”下拉框。若仍出现旧弹窗，说明尚未在扩展管理页重新加载。

后台地址为 `http://127.0.0.1:43127/`，仍需保持后台运行。暂连接本机版，APK 不受影响。

## 复用已打开的手账

新版优先切回搜索来源对应的手账标签页，其次使用已打开的本机手账。通过地址片段弹出保存确认框，不刷新页面，保留浏览状态。没有手账标签页才新建。

更新扩展后，请刷新原来的手账页面一次，让它加载接收保存请求的新逻辑；以后无需每次刷新。若同时存在多个手账标签页，优先来源页，其次最近已注册页面。
