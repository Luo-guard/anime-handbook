| A5 | cover_info 只读 id/image_url，封面不再展开剧集或关联收藏；桌面缓存封面通过文件版本 ETag 在读取图片正文前返回 304；下载文件以临时文件原子发布。线上封面也使用轻量查询和私有条件响应。 |
| A9 | 静态资源 ETag、gzip、Vary: Accept-Encoding、压缩与原始表示独立校验，支持 304。保留重新验证策略，避免开发中同 URL 更新后继续使用旧脚本。个性化 HTML 保持 private/no-store；用户记录图片仍保持私有隔离。 |
| B2/B3 | 收藏搜索 120ms 防抖；卡片按条目 ID 增量复用，不重建未变化节点，失败图片仍可重试。点击、键盘、移入、拖动监听委托至网格，仅安装一次。 |
| B6 | 设置保存独立控制器，单次进行中保护与禁用按钮；验证失败、取消和网络错误后恢复按钮。 |
| D4 | 快照先只读拷贝到暂存库，检查 integrity_check 结果、必要表与迁移后的可读性；备份当前库后通过 SQLite backup 恢复至原文件，取消 os.replace 活库。按数据库路径共享连接门闩和修订号，同一路径的多个服务实例也能互相协调。 |
| D5 | 账号切换使用独占门闩；请求与账号相关后台任务持有共享租约。请求绑定一组服务，旧请求完成前不能切换；新服务全部建立成功后再激活账号。失败不会留下半切换状态。 |
| D6 | 公共 JSON 读取入口限制大小、媒体类型、编码、对象形状、Content-Length 与完整读取；拒绝分块输入，对读取超时返回 408，对超大内容返回 413。 |
| E | 异常统一记录类型/调用位置与编号，不记录正文、查询串、Cookie 或异常原文；非预期错误不向客户端泄漏内部细节。区分上游超时/不可达与客户端断线。入口配置轮转日志并在退出时关闭；恢复性后台异常也有记录。 |
| F | RequestHandler 保留为稳定入口，读/创建/更新/删除路由分别拆为控制器；设置归一化与保存集中到 settings_service；收藏网格与设置保存使用独立命名空间控制器；删除无调用的旧删除方法和 B 站搜索开关函数。原前端函数仍作为兼容接口，index.html 明确加载顺序，由整页启动与功能测试验证依赖，不做无验证的全局改名。 |

## 测试入口

最终验证：后端 263 项通过（121.45 秒），前端 33 个检查通过。压力测试范围见 G2 行。

- 后端：`python -m unittest discover -s tests`
- 加固专项：`python -m unittest discover -s tests -p test_hardening.py`
- 前端：逐一运行 `tests/verify_*.cjs`；新增 transport_faults、settings_save、collection_performance。
- 扩展回归使用临时端口、临时扩展副本及真实测试 HTTP 服务，不再依赖对固定端口的浏览器请求拦截，避免扩展创建标签页时误连正在运行的后台。

这些是明确工作负载下的回归检查，不能据此承诺任意并发量或所有网络环境。所有数据库与云端故障测试使用临时数据或模拟服务；未部署服务器、未重启真实本机后台。生效需重启后台并刷新网页。
