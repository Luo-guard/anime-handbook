## 4. 最后一个功能：编辑记录的时间选择

提交 `a40b15b`，已同步并重启本机后台。

- 时间线编辑及番剧详情的评论编辑点击保存，统一弹出三个单选项：保留原时间（默认）、改为当前时间、保留原记录并另存一条。
- 取消/返回编辑不提交，草稿保留；提交进行中保护防止连点。
- `static/modules/records.js`：`chooseRecordTimeMode()`、`saveEditedRecord()`；详情评论调用同一保存流程。
- 现有 `PATCH /api/events/{id}` 增加可选 `time_mode`（`keep` / `now` / `copy`），默认 `keep`；copy 模式要求 UUID 格式 `copy_uid`。
- `HandbookDB.update_event()` 在同一事务中处理；keep/now 保留 record_uid，now 同时更新 created_at 和 updated_at。
- copy 不修改原记录，独立标识新增；同一编辑表单保留 copy_uid，重试避免重复插入。
- 复制观看记录以 note 存储，保留文字及主题关联，不再次执行观看动作、不重复增加已看集数；改原观看记录时间可能改变该条观看记录所属统计日期，但不会修改收藏已看进度。
- 没有任意日期时间输入；“当前时间”为后台处理保存请求时的时间。
- 无数据库 schema 迁移；未修改原生安卓编辑流程。API 的旧调用者未传参数仍保留原时间。
- 文件：`handbook/database.py`、`handbook/http_patch.py`、`static/modules/records.js`、`static/modules/details.js`、`static/styles.css`、`static/index.html`。
- 测试：`tests/test_note_versions.py`、`tests/verify_record_time.cjs`；保留记录身份、移动时间后云端不重复、copy 独立且可重试、复制观看不重复计数、非法模式不写入均有覆盖。

## 6. 开发和验证命令

以下命令在项目根运行。`python` 请替换为接手指令提供的固定 Python 3.12 路径，不要随意切版本。

```powershell
$env:PYTHONIOENCODING = 'utf-8'
python -m unittest discover -s tests
node tests/verify_record_time.cjs
node tests/verify_record_editor_height.cjs
node tests/verify_timeline.cjs
```

前端全量（PowerShell，失败即停止；不是每条都强制重跑）：

```powershell
Get-ChildItem tests -Filter 'verify_*.cjs' | Sort-Object Name | ForEach-Object {
    node $_.FullName
    if ($LASTEXITCODE -ne 0) { throw "前端检查失败：$($_.Name)" }
}
```

隔离临时实例，仅在单独测试终端设置环境变量，结束后关闭该终端：

```powershell
$env:ANIME_HANDBOOK_PORT = '43682'
$env:ANIME_HANDBOOK_DATA_DIR = Join-Path $env:TEMP ('handbook-review-' + [guid]::NewGuid().ToString('N'))
python app.py --no-browser
```

- 设置数据目录会抑制自动开浏览器，别在这个终端误启动正式实例。
- UI 使用 headless Playwright；现有测试内有运行时依赖路径，可复用。不要打开有头窗口遮挡用户。
- 部分 verify 脚本依赖运行中的正式服务或硬编码测试端口，先读脚本再决定隔离方案；不要让测试修改真实账号。
- 修改 JS/CSS 后更新 `static/index.html` 对应 `?v=`。
- 修改真实数据库之前备份到 `data/backups/`；查看用 SQLite 只读连接；不要随意 import app/desktop，这些模块可能启动真实服务或修复。
- PowerShell 脚本文件保存 UTF-8 BOM；安装 Python 包必须使用 conda 环境，不向系统 Python/base 直接 pip install。
- 后台更新需重启时，先核对监听端口的进程命令行，再只停止这个手账进程，隐藏窗口启动 `app.py --no-browser`，验证服务恢复。不能结束所有 Python。
