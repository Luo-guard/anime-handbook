# UI review edition · 2026-11-05

## Scope and direction

The existing artwork, user themes, feature structure and data flows stay in place. Covers are the primary visual element; controls, reading surfaces and navigation use a quieter common language. This is a review edition: individual page sections can be retained or reverted after user feedback.

Design references used: `anthropics/skills/skills/frontend-design` and `vercel-labs/agent-skills/skills/web-design-guidelines`. Both were read before implementation; the latter's current upstream checklist was reviewed.

## Tokens

- Reading ink: `#24313b`; secondary text: `#65717b`; separators: `#dfe4e8`.
- Dialog paper: `#fafbfd`; primary paper: `#ffffff`; navigation and active controls inherit the saved theme (default slate `#58677a`). No saved color or background is rewritten.
- Type: installed Chinese UI sans-serif fonts; 26–34 px page headings, 21–28 px dialog headings, 13–14 px body, 11–12 px metadata. No remote fonts.
- Radius: 16 px primary panels, 10–14 px cards/controls, smaller chapter buttons. Shadows are restrained and do not accompany every control.
- Layout: retain the left navigation and current content grid. Titles, toolbars and covers align on the same reading edge. Chapter progress and saved resources stay within the existing detail structure.

## Review / rollback map

`static/ui-refresh.css` is the candidate visual layer, intentionally separate from the original stylesheet while choices remain under review. Its numbered blocks are:

1. Foundation / keyboard focus / reduced motion
2. Shell and sidebar
3. Buttons, inputs, floating controls
4. Collection
5. Weekly schedule
6. Journal / composer
7. Statistics
8. Rankings
9. Details, characters, search and dialogs
10. Settings
11. Responsive adjustments

Reverting a page requires removing its block and that page's responsive overrides in block 11. Reverting all candidate visuals requires removing the `ui-refresh.css` link from `static/index.html`. The skip link can remain independently. Account entry changes are isolated at the end of `server/static/online.css` under `UI review edition`.

The original files were copied to a timestamped `archive/ui-baseline-*` directory with SHA256 metadata before edits. This private archive is excluded from repository sync. The previous tracked baseline is commit `3bfbc94`.

## Boundaries and verification

No database migration, API field, sync rule, external image/font dependency or APK change. The only server adjustment permits serving the new stylesheet in online mode. Desktop and online share the visual layer; native Android retains its independent presentation.

Synthetic-account review uses `tests/verify_ui_refresh.cjs`. It captures the five pages, detail/character panels, composer and every settings category at desktop and narrow sizes; checks document/dialog overflow, visible save button and reduced motion. Cached public poster images can be reused locally for visual inspection; account databases are never read by that fixture. Screenshots are written to the OS temp directory, not published.

The UI checklist review covered visible focus, contrast of normal text, safe-area spacing, native controls, long text, reduced motion, modal scroll containment and named actions. Existing interaction tests cover theme preview/cancel/save, menus, keyboard shortcuts, drag ordering and records. This does not assert a full WCAG certification or a redesign of native Android.
